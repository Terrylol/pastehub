## 背景

文本投递已验证了 PasteHub 的核心交接流程，但首发范围还承诺支持截图和照片。图片投递可覆盖手机与电脑之间最常见的截图交接场景，并让已预置的 SeaweedFS 对象存储真正进入交付路径。

## 变更内容

- 新增匿名图片投递：仅支持 JPEG、PNG 与 WebP，单张最大 10 MB。
- 浏览器支持选择、粘贴与预览图片；创建后复用已有的链接、二维码和六码取件方式。
- 浏览器通过受限的预签名 URL 将图片直传 SeaweedFS S3 兼容网关，服务端在完成阶段校验对象并发布投递。
- 投递删除、过期和未完成上传会清理对应对象；取件页只获得短时有效的图片读取 URL。
- 保持现有文本 API 和用户流程兼容，不引入账号、文件传输或端到端加密。

## 能力范围

### 新增能力

- `image-transfer`：匿名临时图片的上传、发布、读取、删除和过期清理。
- `image-transfer-web`：浏览器中粘贴/选择图片、预览、上传、展示和取件的体验。

### 修改的能力

- 无。

## 影响范围

- 后端增加图片投递 API、S3 存储适配、对象校验和清理逻辑。
- 数据模型增加图片类型、对象键、MIME 类型、大小和上传状态。
- 前端扩展首页编辑器、创建结果与取件页面。
- 本地 Compose 的 SeaweedFS 需要补齐 Filer 持久化与 S3 凭据配置，供开发和集成测试使用。
